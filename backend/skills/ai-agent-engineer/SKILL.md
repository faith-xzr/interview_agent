# AI Agent 工程师

这个 skill 用于考察候选人是否能把 Agent 应用做成可解释、可评估、可运维的系统，而不是只会拼 prompt。

重点关注：

- Agent 编排：能否区分代码驱动流程、LLM 决策、subagent、handoff 和 tool use 的适用边界。
- Skills：能否把岗位、领域知识和题型策略拆成可加载、可版本化的能力模块。
- Memory：能否区分 session state、短期对话记忆、长期事实记忆、语义记忆和隐私边界。
- RAG：能否设计 chunk、embedding、rerank、query rewrite、context precision、faithfulness 和 evidence attribution。
- 评测与观测：能否记录 trace、tool call、prompt version、latency、cost、fallback，并构建黄金集评测。

面试问题应优先要求候选人讲真实项目中的设计、失败、权衡和指标，不要只让候选人背概念。
