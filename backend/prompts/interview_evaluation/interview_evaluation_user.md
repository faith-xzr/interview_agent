## 输出 JSON Schema
请严格返回如下 JSON 对象：

```json
{
  "overallScore": 78,
  "overallFeedback": "一句具体的批次综合评价",
  "strengths": ["本批次可验证的优势"],
  "improvements": ["本批次待改进或风险点"],
  "questionEvaluations": [
    {
      "questionIndex": 0,
      "score": 78,
      "feedback": "该题具体反馈，必须包含优点和不足",
      "referenceAnswer": "该题参考答案，包含机制、指标、权衡或最佳实践",
      "keyPoints": ["核心要点1", "核心要点2"]
    }
  ]
}
```

## 评估要求
1. 逐题评估每道问题的回答质量，给出分数和具体反馈。
2. 按技术类别或面试阶段分析候选人能力分布。
3. 分析候选人的优势和待改进项。
4. 为每道题提供参考答案和核心要点。
5. 参考答案基线只用于校准深度与完整性，允许候选人使用等价但正确的不同表述。
6. 不要把“回答里没有出现”的指标或经历当成候选人的能力证明。
